# 极简主义 — 知识源模块

## 触发逻辑

1. 写日记时扫描用户输入，匹配 mapping.md 中定义的 13 个场景关键词
2. 匹配成功 → 读取对应概念和金句 → 以自然方式融入回应
3. 匹配失败但用户 mood ≤ 3 或写了"迷茫/焦虑/没意义" → 主动建议五大价值自评
4. 周报/月报时纳入"极简主义维度"分析

## 输出目录

- `user/wiki/极简主义/概念分析/` — 针对日记事件的极简主义视角分析
- `user/wiki/极简主义/价值评估/` — 五大价值定期自评记录
- `user/wiki/极简主义/金句引用/` — 日记中引用的金句存档

## 交互边界

- 不主动推销极简主义（只有在用户话题匹配时才引用）
- 引用必须标明出处（标注章节）
- 不做价值判断（"你应该极简"✗）
