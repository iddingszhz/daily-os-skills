# 《钝感力》结构化摘要

> 全书结构：序 + 16 个独立章节，逐章论述钝感力在不同领域的运用。

---

### 序

- **核心内容**：介绍"钝感力"是作者新造的词，直译为"迟钝的力量"。
- **关键论点**：
  1. 在日文中有"钝感"一词，但无"钝感力"，这是作者的创造。
  2. 钝感力作为一种为人处世的态度和人生智慧，比激进、张扬在竞争激烈的社会中更容易生存。
  3. 作者从医学角度（作者是医学博士）阐述其合理性。
- **背景**：全书的总纲，定义核心概念。

---

### 第一部分 我们丧失了某种才能

- **核心主题**：钝感是一种才能，一种让才华开花结果的力量。
- **关键论点**：
  1. 提起"迟钝"通常有贬义，但扩展到人体各部位，钝感反而优越。
  2. 被蚊子叮咬的例子——小A敏感红肿，小B钝感毫不在乎。
  3. 小K的故事——被上司当众责骂，次日照常上班，精神抖擞。
  4. 敏感的O先生——才华横溢但因自尊心过强，被退稿后一蹶不振，最终在文坛消失。
  5. 是否有钝感力，决定了有才能的人能否成功。
- **行动建议**：
  1. 被批评后尝试迅速翻篇，不过夜。
  2. 区分"敏感的才华"和"钝感的坚韧"。

### 第二部分 在斥责声中成长的名医

- **核心主题**：面对不断斥责以"唯唯诺诺"应对，反而能学到最多。
- **关键论点**：
  1. 对健康最重要的就是全身血液顺畅流淌，被斥责也不气馁是关键。
  2. S医生的故事——面对教授喋喋不休的指责，永远回答"是，是"。
  3. S医生手术进步最快，后来成为最出色的外科医生，最终当上大医院院长。
  4. 七十五岁高龄的S医生至今无病无灾，十分健康。
  5. 那些高龄而健硕的人，基本都不太听别人讲话。
- **行动建议**：
  1. 面对指责尝试用"是，是"回应，内心不必太当回事。
  2. 不对别人的话逐一分析，选择性接收。

### 第三部分 血液因此畅流

- **核心主题**：钝感力通过自律神经影响血液循环和整体健康。
- **关键论点**：
  1. 血管由自律神经控制，包括交感神经和副交感神经。
  2. 紧张、烦躁让血管变窄，放松、快乐让血管舒张。
  3. 赛里埃的实验——老鼠因持续精神压力患上胃溃疡。
  4. 精神压力分有益和有害：忙碌但有成就感则有益；无事可做可能反成压力。
  5. 钝感的人和敏感的人相比，前者不会造成器官的消耗。
  6. 五官（视觉、听觉、嗅觉、味觉、触觉）过于敏感反而带来负面影响。
- **行动建议**：
  1. 刻意放松心态，保持开朗。
  2. 不要对五官信息过度反应。

### 第四部分 睡眠良好的能人

- **核心主题**：睡眠能力是钝感力的核心代表，是人的基本能力。
- **关键论点**：
  1. 睡眠能力包括入睡和起床两方面。
  2. 睡眠差的人一生可能浪费近六万小时。
  3. 成功的各行各业人士几乎都是"倒头就睡、睁眼即起"的人。
  4. 作者通过两年训练（暗示法）学会随时起床。
  5. 失眠的人大多是凡事想不开的类型。
  6. 逆向失眠疗法——"睡不着就不睡了"反而能入睡。
- **行动建议**：
  1. 上床后不想无聊的事。
  2. 如果失眠，尝试告诉自己"睡不着就不睡了"。

### 第五部分 得寸进尺的才能

- **核心主题**：因表扬而得寸进尺，是钝感力的重要表现形式。
- **关键论点**：
  1. 需要有人做"领路人"给予称赞和鼓励。
  2. 酒吧妈妈桑的鼓励——"你很有才华呀"拍着肩膀说，让作者重拾信心。
  3. 画家A先生——被邻居大婶表扬后拼命作画，最终成为著名画家。
  4. 作者被中山老师表扬和歌，从此喜欢上国语，成为作家。
  5. 对孩子不应娇生惯养，但发现了优点就应该及时表扬。
  6. 一句话既可以救活一个人，也可以杀死一个人。
- **行动建议**：
  1. 收到表扬就真的信以为真，趁热打铁。
  2. 教育孩子时多表扬少批评。

### 第六部分 肠胃钝感的男人

- **核心主题**：肠胃的钝感是身体健康的基础，过度清洁反而降低抵抗力。
- **关键论点**：
  1. 旅行时大家因食物中毒纷纷拉肚子，只有小A一切正常。
  2. 小A很沮丧——"我希望和大家一起拉肚子"，因为他不想与众不同。
  3. 小A在贫穷环境中长大，吃过各种"杂菌"，反而抵抗力强。
  4. 环境卫生越好，身体抵抗力越弱。O157感染时只有日本人得病。
  5. 对环境卫生不必过于神经质，差不多就行了。
  6. 多年后偶遇小A，他依然声音洪亮、无忧无虑。
- **行动建议**：
  1. 不要过度追求无菌环境。
  2. 适当锻炼肠胃的抵抗力。

### 第七部分 被爱的女神射中

- **核心主题**：恋爱中钝感力是不可或缺的武器，特别是对男性而言。
- **关键论点**：
  1. 没有"恋爱学"一说，恋爱是非理性的感情世界。
  2. 男人和女人是完全不同的生物，不能仅靠语言理解对方。
  3. 男性天性急躁，但追求女性最忌讳的就是焦躁。
  4. 女性喜欢被追求，即使不中意也可能在执着追求下被打动。
  5. 被拒绝一次就放弃的人永远追不到心仪的女性。
  6. 钝感的肠胃也是魅力——和女性吃饭时狼吞虎咽让人放松。
  7. 房间适当脏乱反而让女性觉得放松。
- **行动建议**：
  1. 追求女性时不因一次拒绝而放弃。
  2. 和女性进餐时不要挑食，大快朵颐。

### 第八部分 为了维系婚姻生活

- **核心主题**：婚姻是漫长的容忍之路，钝感力是守护婚姻的关键。
- **关键论点**：
  1. 编辑因为挤牙膏方式与妻子吵架——"牙膏管效应"。
  2. 新婚时觉得"可爱的指痕"，十几年后变成了"无法容忍的毛病"。
  3. 争吵的原因其实毫无道理可言，全凭感觉差异。
  4. 在乎的人耿耿于怀，不在乎的人完全不放在心上。
  5. 钝感的人一开始就不会发生口角。
  6. 越是神经质的人，对对方做的事越在意，关系积累的隐患越多。
  7. 结婚时间越长，越不该在某些地方过于在意。
- **行动建议**：
  1. 对伴侣的小毛病不计较。
  2. 提醒自己"牙膏管效应"，区分真正重要的事和无所谓的事。

### 第九部分 为了战胜癌症

- **核心主题**：钝感力在癌症预防、治疗和康复的全程都至关重要。
- **关键论点**：
  1. 癌症成因除了抽烟、有害物质等，自律神经失调是重要因素。
  2. 性格内向、神经质的人更容易患上癌症。
  3. 拥有钝感力的家族不易患癌——不拘小节的父母培养出大方的孩子。
  4. 患癌后性格开朗、积极进取的人治愈率更高。
  5. A先生患肝癌后反而激起了抗争之心，埋头工作，恢复情况令医生吃惊。
  6. 癌细胞不过是寄居在主人身上的寄生虫，不必畏惧。
  7. 治愈后的五年恢复期，钝感力帮助忘掉恐惧，积极生活。
- **行动建议**：
  1. 保持不拘小节、悠闲自在的生活态度。
  2. 万一患癌，保持"我一定要把这家伙赶出去"的坚定态度。

### 第十部分 女性的强大之一

- **核心主题**：女性在出血和创伤方面远强于男性，是造物主的设计。
- **关键论点**：
  1. "弱者，你的名字叫男人"——反转莎士比亚名言。
  2. "一千金，二公子"——女儿比儿子好养活。
  3. 男孩出生率高于女孩，但到成人时人口持平，之后女性逐渐增多。
  4. 作者亲身经历：宫外孕破裂出血几乎二分之一的患者被救活。
  5. 妇科医生解释："教科书上说出血量达三分之一会死，但那是男性。"
  6. 女性每个月来例假，已经习惯出血。
  7. 六年后的重逢——被救的女性生了一个孩子，取名"淳一"。
- **行动建议**：
  1. 重新认识女性身体的强大。

### 第十一部分 女性的强大之二

- **核心主题**：女性在耐寒和耐痛方面也远强于男性。
- **关键论点**：
  1. 女性体内有较厚的脂肪层，相当抗寒。
  2. 作者滑雪时将登山服借给女孩，自己得了重感冒，女孩却一切正常。
  3. 女性对疼痛的忍耐力远强于男性——分娩的痛苦远远超过胆结石和肾结石。
  4. 经历分娩之痛后，女性竟然还会说"我想再要一个孩子"。
  5. 如果是男人负责传宗接代，大多数会在怀孕五个月时叫苦连天。
  6. 造物主将女性创造得坚韧而钝感，是为了让人类持续繁衍。
- **行动建议**：
  1. 理解女性的生理优势是造物主的安排。

### 第十二部分 感谢嫉妒与讽刺

- **核心主题**：被人嫉妒和讽刺时，以钝感力化负面为正面，甚至表示感谢。
- **关键论点**：
  1. 嫉妒和中伤是常见的人际伤害，关键在于如何应对。
  2. 男人的嫉妒主要在工作和社会地位方面，不比女性弱。
  3. 小A和小B的故事——小B因嫉妒散布对小A不利的谣言。
  4. 被嫉妒的幸福——嫉妒你的人说明对方不如你。
  5. "谢谢你总是这么嫉妒我。托你的福，我会更加努力的。"
  6. 对讽刺的钝感——老太太穿花哨衣服的故事。
  7. 老太太听不出讽刺，坦然接受所有称赞，反而慢慢穿出了合身感。
- **行动建议**：
  1. 被人嫉妒时，转换视角为"说明我比他强"。
  2. 听到讽刺时，只照字面意思理解，不当回事。

### 第十三部分 恋爱的能力

- **核心主题**：维持长期恋爱关系需要原谅对方的钝感力。
- **关键论点**：
  1. 恋爱初期需要敏感，但长期维持需要钝感。
  2. 对方爽约或有小背叛时，过于敏感会导致关系崩溃。
  3. K先生从坚定的日餐派变成西餐派——恋爱改变了一个人。
  4. K先生能在不惑之年改变自己，正是钝感力的表现。
  5. S子小姐和已婚T先生的婚外情——"没有钝感力根本无法坚持下去"。
  6. "所谓爱情，就是宽容和原谅对方吧。"
  7. 男女在身体和生理上截然不同，需要互相原谅。
- **行动建议**：
  1. 恋爱中对小摩擦宽容一些。
  2. 为了爱人愿意改变自己的习惯。

### 第十四部分 为了更好的生存

- **核心主题**：在集体（公司）中生存，钝感力是出人头地的必要条件。
- **关键论点**：
  1. 男编辑K被女编辑的娇声和香水折磨——最终换座位了事。
  2. 但并非所有人都有好上司，此时钝感力是唯一的解药。
  3. 公司是一个各种毛病互相碰撞的场所。
  4. 列举各种惹人讨厌的毛病：抖腿、蘸唾沫翻书、吹嘘等。
  5. 有些毛病可以改，有些是体质问题，不可能改。
  6. 只有对各种令人不快的毛病忽略不计，才能开朗、大度地生活。
  7. 拥有钝感力的员工对公司来说是宝贵人才。
- **行动建议**：
  1. 对同事的小毛病视若无睹。
  2. 分清哪些可以改变、哪些只能接受。

### 第十五部分 适应环境的能力

- **核心主题**：适应环境能力的原点就是钝感力，健康的身体就是充满钝感力的身体。
- **关键论点**：
  1. 同样受伤，小A化脓，小B五天痊愈，小C像什么都没发生过。
  2. 自愈能力就是皮肤钝感力的强弱。
  3. 同住一个房间，小A没事，小B流鼻涕，小C感冒发烧。
  4. 人体对外界温度变化的适应能力称为"恒常性"。
  5. 适应能力也包括适应人际关系和社会环境的能力。
  6. 国际化时代，无论到哪个国家都能精神饱满地生活——这就是钝感力。
- **行动建议**：
  1. 培养身体的钝感力——增强基础体力。
  2. 培养精神上的适应力——无论在哪里都能活下去。

### 第十六部分 伟大的母爱

- **核心主题**：母爱集钝感力之大成，可以原谅一切的情感是钝感力的原点。
- **关键论点**：
  1. 母亲喂奶时敞开胸膛，无所顾忌——这正是钝感力的表现。
  2. 母亲接触孩子的粪便，闻气味、看颜色——只有母亲才能做到。
  3. 对孩子的哭闹，母亲逐渐习惯，这是上天单独赋予母亲的能力。
  4. 父亲在哭闹面前会逃走，母亲不会。
  5. 孩子吃饭时弄得一片狼藉，母亲毫无嫌弃。
  6. 母亲可以原谅犯罪的孩子——这种宽广的胸怀是钝感力的极致。
  7. 生过孩子的女性、未生孩子的女性和男性，三者之间的钝感力有决定性的差距。
- **行动建议**：
  1. 理解母爱与钝感力的深刻关联。
  2. 从母亲身上学习无条件包容与原谅的钝感力。
