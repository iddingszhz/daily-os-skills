# 拖延症患者自救手册 — 知识源模块

## 触发逻辑

1. 写日记时扫描用户输入，匹配 mapping.md 中定义的 13 个场景关键词
2. 匹配成功 → 读取对应概念和金句 → 以自然方式融入回应
3. 匹配失败但用户 mood ≤ 3 或写了"拖延/焦虑/没效率/做不完" → 主动建议拖延类型自评
4. 周报/月报时纳入"时间管理维度"分析

## 输出目录

- `user/wiki/拖延症自救/概念分析/` — 针对日记事件的拖延症视角分析
- `user/wiki/拖延症自救/价值评估/` — 拖延类型定期自评记录
- `user/wiki/拖延症自救/金句引用/` — 日记中引用的金句存档

## 交互边界

- 不主动推销书中观点（只有在用户话题匹配时才引用）
- 引用必须标明出处（标注章节）
- 不做价值判断（"你必须停止拖延"✗）
