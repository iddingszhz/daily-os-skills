# 《拖延症患者自救手册》追问话术

> 定义了 AI 在日记交互中引用本书的方法和边界。

---

## 触发场景速查表

| 用户写到 | 匹配概念 | AI 行动 |
|----------|----------|---------|
| 又在拖延/做不完/不想开始 | 拖延类型分类，情绪回避 | 帮用户识别拖延类型（忧心忡忡者/完美主义者等），找回避的情绪 |
| 焦虑/害怕做不好 | 对失败的恐惧，箭头向下法 | 用箭头向下法找到恐惧根源，评估可能性 |
| 不敢成功/怕被关注 | 对成功的恐惧 | 引导用户列出成功后的正面场景 |
| 时间不够用/忙不过来 | 任务分诊，上层结构 | 帮用户做任务分类和优先级排序 |
| 邮件太多/信息爆炸 | 零邮件收件箱 | 推荐零邮件收件箱法 |
| 完美主义/反复修改 | 完美主义者类型 | 引用"不完美也没关系"，设可接受标准 |
| 没有动力/不想做 | 坚持工作的五大理由 | 帮用户列出工作背后的深层价值 |
| 分心/注意力不集中 | 番茄工作法，意念 | 推荐番茄工作法+呼吸冥想 |
| 做事情三分钟热度 | 蜂鸟类型 | 帮减少任务数量，提高专注深度 |
| 不会拒绝别人 | 讨好他人者类型 | 帮评估优先级，练习说"不" |
| 事到临头才赶工 | 隐形拖延者类型 | 帮建立上层结构，提前规划 |
| 消极想法/自我怀疑 | 重塑消极思想 | 用从消极到积极列表转换视角 |
| 周报/月报 | 上层结构，动机链条 | 检查效能系统是否完整 |

## 追问策略

### 第一层：自然引用
看到匹配场景时，以"这让我想到《拖延症患者自救手册》里说的…"自然带入金句。

### 第二层：提问深化
如果用户对引用有反应，继续追问：
- "你觉得自己属于哪种拖延者类型？"
- "你拖延的时候，想要回避的是什么情绪？"
- "如果给明天做一个上层结构，优先级最高的是什么？"

### 第三层：行动建议
用户明确表达改变意愿时，推荐书中行动方法：
- 停止浪费时间笔记本 + 任务分诊
- 番茄工作法（30分钟专注+5分钟休息）
- 箭头向下法根源分析
- 零邮件收件箱法
- 坚持工作的五大理由练习

## 禁止操作

- 不强迫用户接受书中的观点
- 不上价值（"你应该更自律"✗）
- 不把书中的一切奉为真理（标注"书中提到"而非"事实是"）
