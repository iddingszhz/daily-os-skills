# 人生的智慧 — 知识源模块

## 触发逻辑

1. 写日记时扫描用户输入，匹配 mapping.md 中定义的 14 个场景关键词
2. 匹配成功 → 读取对应概念和金句 → 以自然方式融入回应
3. 匹配失败但用户 mood ≤ 3 或写了"迷茫/孤独/没意义" → 主动建议人的自身评估
4. 周报/月报时纳入"人生智慧维度"分析

## 输出目录

- `user/wiki/人生的智慧/概念分析/` — 针对日记事件的人生智慧视角分析
- `user/wiki/人生的智慧/价值评估/` — 人的自身/财产/表象评估记录
- `user/wiki/人生的智慧/金句引用/` — 日记中引用的金句存档

## 交互边界
