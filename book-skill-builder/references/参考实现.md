# 参考实现：minimalism-book.skill

位置：`~/.config/opencode/skills/minimalism-book.skill/`

这是第一个用本生成器流程手工构建的 Book Skill，可作为所有后续技能的格式参考。

## 关键参考文件

| 文件 | 用途 |
|------|------|
| `SKILL.md` | 8 步安装流程的标准写法 |
| `_meta.json` | cocoloop 元数据格式 |
| `module/module.md` | knowledge-source 类型模块的 frontmatter 和结构 |
| `module/prompts/追问话术.md` | 触发场景速查表格式、追问三层策略 |
| `module/templates/价值评估模板.md` | 通用模板的 frontmatter + Obsidian callout |
| `module/templates/极简行动模板.md` | 行动记录模板格式 |
| `knowledge/concepts.md` | 15 个概念的格式（定义+关联+章节+原文） |
| `knowledge/quotes.md` | 28 条金句的格式（原文+标签+章节+背景） |
| `knowledge/structure.md` | 7 章的结构化摘要格式 |
| `knowledge/mapping.md` | 13 个日记场景映射格式 |

## 产出规格速查

```
实体数量：12-15 个
金句数量：20-30 条
场景映射：10-15 个
章节摘要：逐章，每章 3-5 个论点 + 2-3 条行动建议
文件总数：11 个（含 L3 全文则为 12）
```
