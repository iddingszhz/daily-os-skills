# 《反脆弱》追问话术

> 定义了 AI 在日记交互中引用本书的方法和边界。

---

## 触发场景速查表

| 用户写到 | 匹配概念 | AI 行动 |
|----------|----------|---------|
| 工作没安全感/怕被裁员 | 三元结构，脆弱性 | 帮分析当前职业是约翰型（脆弱）还是乔治型（反脆弱），建议杠铃策略 |
| 想创业但害怕失败 | 反脆弱性，可选择性，过度补偿 | 引用"失败是信息而非耻辱"，鼓励小规模试错 |
| 投资亏了/怕亏钱 | 杠铃策略，非线性，黑天鹅 | 分析投资组合的凸性，建议 90/10 杠铃配置 |
| 生病了/纠结要不要治疗 | 医源性损伤，天真的干预 | 区分必要干预和过度干预，引用"首先不要造成伤害" |
| 看新闻很焦虑 | 噪声 vs 信号，脆弱推手 | 提醒减少信息摄入频率，区分信号和噪声 |
| 觉得人生太稳定/平淡 | 反脆弱性，过度反应 | 建议适度引入压力源，引用"没有波动就没有稳定" |
| 做决定犹豫不决 | 可选择性，杠铃策略 | 帮识别哪些选项具有不对称性（损失有限收益无限） |
| 被人批评/攻击 | 信息的反脆弱性 | 引用"批评让一本书更出名"，建议不受负面信息影响 |
| 工作太忙/效率低 | 否定法，减法知识 | 引导做减法而非加法，帮识别该停止什么 |
| 被同事抢功劳 | 切肤之痛，伦理 | 引用"不承担风险的人不配获得收益" |
| 想学习新技能 | 实践 vs 理论，教鸟儿飞行 | 建议在行动中学习而非靠书本理论 |
| 对社会/政治不满 | 脆弱推手，自上而下的干预 | 引用"国家无能时反而有益"，引导思考系统脆弱性 |
| 面对重大抉择 | 杠铃策略，可选择性 | 帮分析两面极端方案，避免中间路线 |
| 想要创新/突破 | 过度补偿，可选择性 | 引用"对挫折的过度反应释放的能量成就了创新" |
| 觉得活得太累 | 否定法，减法知识 | 帮识别生活中应削减的事物，减少医源性压力 |

## 追问策略

### 第一层：自然引用
看到匹配场景时，以"塔勒布在《反脆弱》中谈到…"自然带入金句。

### 第二层：提问深化
如果用户对引用有反应，继续追问：
- "你现在的工作更像约翰（银行职员）还是乔治（出租车司机）？"
- "这件事中，你能识别出脆弱推手吗？"
- "如果采用杠铃策略，你的两个极端方案是什么？"
- "这件事里你的损失上限是多少？"

### 第三层：行动建议
用户明确表达改变意愿时，推荐书中行动方法：
- 杠铃策略（极端保守+极端冒险）
- 减法行动（识别该停止/削减的事物）
- 斯多葛式心理练习（预想最坏情况）
- 识别医源性损伤（区分有害干预和有益干预）

## 禁止操作

- 不强迫用户接受反脆弱观点
- 不上价值（"你应该拥抱不确定性"✗）
- 不把书中的一切奉为真理（标注"书中提到"而非"事实是"）
